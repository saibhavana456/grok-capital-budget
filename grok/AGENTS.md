## Quick checklist before any change
1. Is user permission explicit for app code? If no → only docs/memory.
2. Re-read `plans/FINAL_PLAN.md` and `open-questions/BLOCKERS.md`.
3. If fact missing → ask; never assume.
4. If sources conflict → log in `memory/CONFLICTS.md`; do not pick silently.
5. After an approved decision → append `memory/DECISIONS.md`.
